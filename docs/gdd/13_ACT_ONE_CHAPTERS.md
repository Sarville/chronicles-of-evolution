документы говорят «первые 180 минут» или «Timeline #1», это теперь описание
контента библиотеки, а не одного забега — см. их обновлённые шапки.

---

# 1. Зачем нужен этот документ

`DECISIONS_ACT_STRUCTURE.md` фиксирует: вместо одного 105–180-минутного забега
RNA→Ash игрок проходит **пять коротких попыток** (~3–4 часа суммарно), каждая
заканчивается раньше предыдущей стадии финала и по-своему, каждая начинается с
исправления, которое Архив внёс в ответ на причину предыдущей гибели — и это
исправление создаёт новую уязвимость. Задача этого документа — зафиксировать,
что именно меняется от главы к главе на уровне gameplay-контракта: точка входа,
точка выхода (era cutoff), новая механика давления/коллапса, цель, и как
переиспользуется уже реализованный `T1-0…T1-6` контент.

---

# 2. Один принцип вместо четырёх новых систем

Каждая из глав `T1–T4` заканчивается новым типом коллапса (не `Ash`). Вместо
четырёх разных систем кризиса — **один переиспользуемый событийный паттерн**,
упрощённая версия того, что уже построено для Great Filter: одно authored
anomaly-событие, вводящее угрозу как факт («rising»), затем одно mandatory
choice-событие с тремя вариантами, которое определяет subtype/epitaph, но не
отменяет сам коллапс — и переход в ending. Не нужен отдельный player-facing
meter вроде `World Tension`: главы `T1–T4` короче `T5` на порядок, и полная
4-фазная (`C0–C4`) Stability-последовательность туда не помещается по темпу.
Каждая глава меняет только:

- тексты rising- и final-события;
- какие предыдущие решения главы (governance, automation-risk и т.п.) входят
  в условие final-события;
- финальный ending ID/title/subtype.

Ни одна из глав `T1–T4` не реализуется как отдельный bespoke crisis engine —
обе события используют тот же generic event/goal-контракт, что и остальные
authored события GDD (`08_EVENTS_AND_CHOICES.md`).

`T5` — единственная глава, которая использует буквально существующий полный
`Stability`/`World Tension`/`EV-CR-01..03` 4-фазный кризис почти без
изменений (см. §7) — она одна достаточно длинная (~45–60 мин), чтобы нести
такую последовательность.

поэтому не нужен отдельный player-facing meter вроде `World Tension`;
предвестник коллапса подаётся одним authored anomaly-событием

`docs/gdd/07_GOALS_AND_MILESTONES.md` §4–8, `08_EVENTS_AND_CHOICES.md`.

исследование/побочный контент. Это telemetry-цель, не жёсткий таймер — как и
везде в проекте, финальные числа утверждаются после реализации и плейтеста
(`ACT-006`).

Только два species/skin swap за весь акт (`T2`, `T4`) — см. `ACT-002`. `T3`
играет тем же видом, что `T1`, но со стартовым tech grant. `T5` возвращает
исходный вид `T1` — «swap budget» на этом исчерпан. Swap — косметика (лейблы,
1–2 flavor-способности); полная глубина трейтов остаётся за Актом 3.

# 4. Точка входа каждой главы

`T1` — единственная глава, которая реально проигрывает биологию
(`M01…N07`, `01_FIRST_120_MINUTES.md` §4–10) с нуля. Остальные главы **не
повторяют биологический этап**: по сюжету Архив выдаёт уже разумный/уже
осевший вид с конкретным стартовым условием, и glimpse предыдущей биологии
существует только в Chronicle предыдущей главы, не как повторный gameplay.

| Глава | Входит в мир на стадии | Экономика на старте |
|---|---|---|
| `T1` | `MOLECULAR` (RNA) | пусто, как сейчас |
| `T2` | `TRIBE`-эквивалент, `run.chapter = 'T2'`, рассеянный старт (см. `docs/scenario/01_TIMELINE_01_SCRIPT.md` §5.1) | стартовый пакет Population/Food как при текущем `EARLY_CIV.civilizationStart`, плюс модификатор рассеянного расселения (ниже плотность построек/защиты) |
| `T3` | `SETTLEMENT`-эквивалент, с грантом ранних укреплений | пакет Settlement-контента (Farming/Housing/Workshop) плюс один бесплатный defensive building/tech с начала |
| `T4` | `CITY`-эквивалент, с более высоким стартовым Cognition/Writing | пакет City-контента плюс завершённый `Writing`/бонус к Knowledge-темпу с начала |
| `T5` | `MODERN`-эквивалент (порог перед `ERROR 17`) | пакет Modern/Atomic контента; стартовые флаги ссылаются на исходы `T1–T4` (см. §7) |

Реализация точки входа — не новый онбординг с нуля, а `civilizationStart`-подобный
грант (как уже существующий `EARLY_CIV.civilizationStart` в `eras.js`), плюс
один или два бесплатных/предзавершённых узла дерева, привязанных к стартовому
условию главы. Экономика/дерево/здания остаются те же данные, что описаны в
`03_EVOLUTION_TREE.md`, `05_BUILDINGS_AND_JOBS.md`, `06_TECH_TREE.md` — новых
веток строить не нужно.

# 5. Цели и вехи по главам

Существующая цепочка `G001–G024` (`07_GOALS_AND_MILESTONES.md`) остаётся
единственным источником целей биологии/цивилизации. Каждая глава использует
**срез** этой цепочки:

```text
T1: G001–G015           (RNA → Tribe)
T2: G015-эквивалент старт → G017   (Tribe-старт → Settlement)
T3: G017-эквивалент старт → G019   (Settlement-старт → City)
T4: G019-эквивалент старт → G021/G022 (City-старт → Industry/Modern)
T5: G022-эквивалент старт → G024   (Modern-старт → Great Filter → Ash)
```

Для `T2–T5` «эквивалент старт» — не повторное выполнение предыдущих G-целей,
а `prerequisites`, уже удовлетворённые стартовым грантом главы. Точная,
canonical нарезка — `docs/gdd/07_GOALS_AND_MILESTONES.md` §3–8:

```text
T1: G001–G015          + G025 (rising), G026 (Мор, ending)
T2: G027–G030          (G030 = Катаклизм, ending)
T3: G031–G034          (G034 = Раскол, ending; G032B governance входит в условие)
T4: G035–G039          (G039 = Авария, ending; G037 automation-risk входит в условие)
T5: G020–G024 (старая нумерация) + EV-NAR-08 intro, синтез-deck
```

Конкретные `targetTimeMs` пересчитываются под budget из §3 этого документа, а
не унаследованы от старой 180-минутной шкалы.

Каждая глава `T1–T4` добавляет один **collapse goal** (последний G в её
диапазоне выше), не являющийся `G0xx`-целью Sapience-цепочки. Формат
идентичен существующему `G024 Пройдите Великий фильтр`: не purchase-цель,
одно rising anomaly-событие → один mandatory choice → ending. Хорошая игра не
отменяет коллапс, только меняет subtype/reward/Chronicle — тот же hard rule,
что уже действует для `G024`/`Ash`.

Новые вехи (`MS`-серия продолжается с существующей `MS01–MS09`, которая не
перенумеровывается — см. `07_GOALS_AND_MILESTONES.md` §9 для полной таблицы
`MS10–MS15`):

| ID | Триггер | Title |
|---|---|---|
| `MS10` | `G026` ending | МОР |
| `MS11` | `G029` | ПЕРВЫЙ ТОЛЧОК |
| `MS12` | `G030` ending | КАТАКЛИЗМ |
| `MS13` | `G031` | КРЕПОСТЬ |
| `MS14` | `G034` ending | РАСКОЛ |
| `MS15` | `G039` ending | АВАРИЯ |

`MS01–MS09` не перенумеровываются и не дублируются по главам: `МЫ ОСТАЛИСЬ`,
`ЭПОХА МАШИН`, `МЫ РАСКОЛОЛИ МАТЕРИЮ` и т.д. остаются вехами «эта эра
достигнута» — их первой достигает живьём та глава, что реально проходит
переход (`T2` для `МЫ ОСТАЛИСЬ`, `T4` для `ЭПОХА МАШИН`, только `T5` для `МЫ
РАСКОЛОЛИ МАТЕРИЮ`), а не каждая последующая глава повторно.

# 6. Новые endings `T1–T4`

Все четыре используют общий, но **облегчённый** вариант паттерна `ENDING_ASH`
(`09_ENDINGS_AND_RESET.md` §16, `docs/scenario/06_ENDINGS_COPY.md` §0):
короткая пауза + локальное затемнение (без белой вспышки — она остаётся за
`Ash`), ending card, 1–2 строки Archive neutral summary, reveal-строка (если
у главы она есть), idempotent reset, CTA `Продолжить синтез` — никогда
`Game Over`/`Попробовать снова`. В отличие от `Ash`, они не показывают
полный многосекционный Archive Summary и ведут **в следующую главу Акта 1**,
а не в Timeline #2/Act 2 teaser (тот остаётся исключительно после `T5`).

| Глава | Ending ID | Title | Визуал коллапса | Archive Fragments (типичный диапазон) |
|---|---|---|---|---:|
| `T1` | `ENDING_BLIGHT` | МОР | диорама тускнеет, population-иконки гаснут по одной | 4–6 AF |
| `T2` | `ENDING_CATACLYSM` | КАТАКЛИЗМ | трещины/разлом ландшафта, диорама рушится | 5–7 AF |
| `T3` | `ENDING_FRACTURE` | РАСКОЛ | диорама раскалывается на изолированные фрагменты | 6–8 AF |
| `T4` | `ENDING_OVERLOAD` | АВАРИЯ | индустриальный skyline гаснет каскадом, как отказ сети | 7–9 AF |
| `T5` | `ENDING_ASH` | ПЕПЕЛ (существующий) | белая вспышка (без изменений) | 14–18 AF |

Меньший AF на ранних главах — это провизорный envelope, не окончательная
формула; суммарно 5 глав должны давать сопоставимую или чуть большую общую
награду, чем старый единый 180-минутный Ash, т.к. игрок теперь пять раз
проходит reset-ритуал вместо одного. Точная балансировка — предмет
`ACT-006`/будущего DS.

Каждый non-Ash ending обязателен так же, как `Ash` был обязателен в старом
дизайне: это не failure state, а запланированный конец главы. Хорошая игра
внутри главы улучшает subtype/reward/Chronicle, не отменяет коллапс —
идентично правилу `09_ENDINGS_AND_RESET.md` §6.

# 7. `T5` — синтез: обязательный слой процедурных «эхо»-событий

`T5` реализуется почти без изменений (`T1-5…T1-6` package) — Modern bridge,
`ERROR 17`, Atomic Theory, `World Tension`/crisis C0–C4, `Last Protocol`,
`ENDING_ASH`, всё как в `08_EVENTS_AND_CHOICES.md`/`09_ENDINGS_AND_RESET.md`
сейчас. Единственное содержательное дополнение, которое требует эта
переделка — новый процедурный event-слой, дающий ощутимую, а не только
продекларированную в интро-строке, форму фразе «Архив смешивает уроки `T1–T4`».

## 7.1 Проблема

Процедурный (не authored) event deck сейчас существует только в самом начале
игры: `deck: 'early_biology'` (`EV-RNA-RESONANCE`, `EV-DNA-TRACE` в
`src/chronicles/config/events.js`) покрывает только molecular-окно. Every
other phase, включая весь Modern/Atomic диапазон, имеет только authored
one-off события — ни одного procedural minor/major deck, хотя
`12_LONG_TERM_PROGRESSION_AND_RESET_ROADMAP.md` §7 требует его для всего `T1`
целиком. Это именно то окно, которое теперь принадлежит `T5`.

## 7.2 Контракт `deck: 't5_synthesis'`

Тот же generic Event Engine, что уже обслуживает `early_biology`
(seeded weighted draw, per-event cooldown, save-сериализуемое deck state) —
новый набор карточек, не новый движок.

```text
window: Modern → Atomic (весь T5 после EV-NAR-08 «Синтез», до Last Protocol)
cadence: minor ~ раз в 2–4 мин; major доступна только после того, как её
  парная minor уже разыграна в этом прогоне (короче T5, поэтому пары
  «minor → major», а не отдельная global cadence)
each pair: precondition — meta.endings.chapterN_subtype установлен для
  соответствующей главы; если флаг отсутствует (глава пройдена иначе или
  save мигрировал без полной истории), пара не входит в eligible pool —
  никаких generic заглушек
effect: небольшой capped grant/Stability-adjacent bonus ИЛИ чистый
  Chronicle-flavor без numeric эффекта (minor карточки); major-карточки —
  explicit risk/reward choice, Chronicle-текст варьируется по конкретному
  subtype прошлой главы
hard rule: ни одна echo-карточка не может предотвратить обязательный первый
  Ash — тот же принцип, что уже действует для EV-CR-01/02
```

## 7.3 Набор карточек — четыре пары (minor + major), по одной на главу

| ID | Precondition | Type | Смысл |
|---|---|---|---|
| `EV-T5-ECHO-BLIGHT-MINOR`/`-MAJOR` | `chapter1_subtype` | flavor | протокол/вспышка, явно ссылающиеся на исход `Мор` |
| `EV-T5-ECHO-CATACLYSM-MINOR`/`-MAJOR` | `chapter2_subtype` | flavor | инфраструктурный запас/толчок, ссылающиеся на исход `Катаклизм` |
| `EV-T5-ECHO-FRACTURE-MINOR`/`-MAJOR` | `chapter3_subtype` | flavor | модель согласия/голос несогласных, ссылающиеся на исход `Раскол` |
| `EV-T5-ECHO-OVERLOAD-MINOR`/`-MAJOR` | `chapter4_subtype` | flavor | диагностика/каскад автоматики, ссылающиеся на исход `Авария` |

Полные тексты, Chronicle-копии (варьирующиеся по конкретному subtype) — в
`docs/scenario/04_STORY_EVENTS.md` §T5-DECK. Разработка UI/эффектов не
должна придумывать числовые модификаторы сверх `grant_resource`/
`adjust_crisis_stability` в пределах, заданных существующим
crisis-балансом (§13 в `02_ECONOMY_FIRST_120_MINUTES.md`).

## 7.4 Флаги

Deck читает только `meta.endings.chapter1_subtype…chapter4_subtype` —
никакого отдельного progress-флага не требуется; полный контракт (включая
species-skin budget и chapter-reset scoping) — `docs/scenario/
05_NARRATIVE_FLAGS.md` §5A/§5B.

# 8. Что НЕ входит в эту переделку

- Полный числовой баланс каждой главы (Stability drain rates, конкретные
  `targetTimeMs`, конкретные starting grants) — предмет отдельного balance
  pass после реализации, как и раньше для `T1` (`02_ECONOMY_FIRST_120_MINUTES.md`
  §16).
- Механическое содержание swap-species (`T2`, `T4`) сверх косметики — полная
  глубина трейтов сознательно отложена до Акта 3 (`ACT-002`).
- `P1–P3` (Акт 2) и Акт 3 — вне скоупа GDD `01–13`; их укрупнённая карта
  переписана в `12_LONG_TERM_PROGRESSION_AND_RESET_ROADMAP.md` §4–5.

`docs/production/TIMELINE_01_REBUILD_PLAN.md` тоже переписан под пять глав
(work-package table §4, `T5`-deck work-item §5) — см. этот файл для
implementation-порядка.
