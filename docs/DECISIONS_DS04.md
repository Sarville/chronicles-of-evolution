# Хроники Эволюции — Decisions addendum DS-04

**Status:** accepted  
**Date:** 2026-09-15

## DS04-DEC-01 — Archive Recall

После первого reset автоматически включается Archive Recall, даже если игрок не потратил AF. Для знакомых CORE-узлов до `N06 Разум`: familiar CORE cost ×0.75, familiar pre-Sapience production ×1.25. Archive Recall не завершает узлы автоматически и прекращает действовать после Sapience.

## DS04-DEC-02 — Timeline #2 pacing

Цель знакомой ранней части Timeline #2 до Sapience: p50 20–28 минут. Без покупок AF целевой диапазон 24–28 минут; с типичной покупкой 2–4 Tier 1 nodes — 20–25 минут. Ниже 18 минут считается чрезмерным сжатием раннего gameplay.

## DS04-DEC-03 — Meta caps

Meta-only production caps: pre-Sapience ×1.60, Tribe/Settlement ×1.35, City ×1.25, Industry/Atomic ×1.15. Familiar CORE cost после meta reductions не может быть ниже 70% canonical cost. Offline efficiency hard cap — 75%.

## DS04-DEC-04 — Retention and hybridization

`AR05` даёт один retained OPTIONAL biological node, который активируется бесплатно только после достижения исходных prerequisites. `AR06` позволяет купить вторую cellular branch по base cost, но без одновременного stacking её numeric effect. `AR09` даёт один secondary biological trait slot с 65% numerical effect.

## DS04-DEC-05 — Archive Intervention balance envelope

Archive Intervention — optional acceleration: один производимый resource, ×1.50, базово 120 секунд, без stacking. Future meta upgrades могут увеличить duration максимум до 180 секунд и stored charges максимум до 3, но multiplier остаётся не выше ×1.50. Нельзя усиливать AF, Population, Stability, World Tension или crisis timer.

## DS04-DEC-06 — Anti-snowball

Archive nodes не увеличивают AF multiplier; нет blanket global production multiplier на всю Timeline; новые/неизвестные ветви проходят по обычному balance; ads не являются частью baseline progression и не дают permanent economy multiplier.
