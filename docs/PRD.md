# PRD — Хроники Эволюции
## Редизайн Evolve для Яндекс Игр / VK Игры
**Версия документа:** 0.1  
**Статус:** рабочий PRD для дальнейшей детализации  
**Целевые платформы:** Яндекс Игры, VK Игры, desktop web, mobile web  
**Базовый проект:** Evolve (`pmotschmann/Evolve`)  
**Ключевая продуктовая идея:** сохранить глубину экономики, prestige-циклов, рас, технологий и позднего контента Evolve, но полностью переработать presentation layer, ранний pacing, цели, сюжетную подачу и mobile UX.

---

# 1. Executive summary

Оригинальный Evolve ценен не интерфейсом, а структурой долгой progression-системы: эволюция → цивилизация → космос → prestige/reset → новые расы, планеты, вселенные, поздние ветки и альтернативные маршруты.

Для Яндекс Игр / VK его предлагается преобразовать в визуальный story-driven incremental:

> Игрок выращивает цивилизации от первой клетки до космоса, приводит их к разным судьбам, сохраняет опыт погибших миров и постепенно выясняет, почему разумные цивилизации снова и снова сталкиваются с Великим фильтром.

Ключевая перемена: reset перестаёт ощущаться как «обнуление чисел». Каждый run становится **законченной историей отдельной цивилизации**, а prestige — **Памятью Архива**, остающейся после её гибели, исхода или трансформации.

### Продуктовые ориентиры
- Первое осмысленное действие: < 20 секунд.
- Первый визуальный unlock: < 60 секунд.
- Первая эволюционная развилка: 8–12 минут.
- Разумный вид: 25–35 минут.
- Племя / поселение: 35–50 минут.
- Индустриальная эпоха: 70–90 минут.
- Первый большой финал/reset: 105–120 минут.
- Первый космос: примерно 3–5 часов суммарной игры.
- Первый Bioseed / новый мир: примерно 8–12 часов.
- За первые 20 часов игрок должен увидеть несколько разных цивилизаций и минимум 2 принципиально разных варианта развития.

Эти числа — **целевой новый баланс**, а не сохранение оригинального pacing Evolve.

# 2. Продуктовая проблема

У Evolve есть несколько сильных системных качеств:
- многоступенчатая progression;
- реальные эволюционные развилки;
- разные расы и traits;
- долгосрочная metaprogression;
- множество reset/end-state механик;
- большой поздний контент;
- высокая реиграбельность.

Но в исходной форме для массового портального игрока есть проблемы:
1. интерфейс воспринимается как таблица ресурсов и кнопок;
2. прогресс плохо визуализирован;
3. игрок не всегда понимает ближайшую и долгосрочную цель;
4. слишком много систем раскрываются без сильной эмоциональной подачи;
5. ранний run слишком долгий для знакомства с prestige-loop;
6. mobile UX нуждается в новой композиции, а не только responsive CSS;
7. история существующих цивилизаций существует главным образом в голове игрока, а не в продукте.

# 3. Product vision

## 3.1 Elevator pitch

**Хроники Эволюции** — incremental-стратегия о развитии жизни и цивилизаций, где каждый run превращается в отдельную историческую линию: от клетки до города, атома, космоса и одного из множества финалов. Гибель цивилизации не заканчивает игру — её память становится инструментом следующего эксперимента.

## 3.2 Fantasy игрока

Не «я оптимизирую +12% добычи камня», а:

- я создаю новую форму жизни;
- наблюдаю, как из неё рождается общество;
- принимаю решения, меняющие внешний вид и правила цивилизации;
- вижу, как город растёт из деревни в индустриальный мегаполис;
- довожу общество до кризиса или космоса;
- получаю уникальную хронику этого мира;
- запускаю новую временную линию уже с накопленным знанием;
- пытаюсь найти цивилизацию, способную пережить Великий фильтр.

# 4. Целевая аудитория

## Основная
Игроки 18–45, которым нравятся:
- idle/incremental;
- технологические деревья;
- цивилизационная progression;
- коллекционирование;
- prestige/meta progression;
- стратегии без постоянного микроконтроля.

## Вторичная
- любители Civilization/Spore/Universal Paperclips/Kittens Game;
- игроки портальных idle-игр;
- mobile casual игроки, которых можно зацепить визуально понятной эволюцией мира.

## Не целевая на старте
Игроки, ожидающие:
- real-time боёв;
- полноценный city-builder с ручной расстановкой сотен зданий;
- сюжетную RPG с персонажами и диалогами каждые 2 минуты.

# 5. Design pillars

## 5.1 «Всегда видно, куда я иду»
У игрока одновременно существуют:
1. **Сейчас** — задача на 30 секунд – 5 минут.
2. **Глава** — цель на 10–30 минут.
3. **Судьба** — крупная цель run: разум, индустрия, атом, космос, финал.

## 5.2 «Мир показывает прогресс»
Числа должны отражаться в диораме:
- больше населения → больше домов и людей;
- фермы → поля;
- металлургия → мастерские и трубы;
- электричество → освещение;
- железные дороги → поезд;
- космос → ракетный комплекс;
- загрязнение → меняется атмосфера;
- экологический путь → зелёная архитектура.

## 5.3 «Reset = история, а не поражение»
Каждый reset:
- получает название;
- иллюстрацию;
- причину;
- итоговые статистики;
- запись в Хронике;
- permanent reward;
- новый кусок метасюжета.

## 5.4 «Новый run реально новый»
Новый run должен отличаться:
- видом;
- traits;
- визуальной темой;
- выбором развития;
- side quests;
- событиями;
- некоторыми производственными правилами;
- доступными концовками.

## 5.5 «Глубина раскрывается слоями»
Сложность оригинального Evolve не удаляется целиком. Она постепенно открывается после нескольких runs.

# 6. Что сохраняем из Evolve

## 6.1 Обязательно сохраняем
- evolution layer;
- базовую ресурсную экономику;
- профессии/население;
- здания;
- технологии;
- traits видов;
- prestige/reset architecture;
- MAD как один из первых исторических финалов;
- Bioseed;
- CRISPR-подобную permanent progression;
- achievements/mastery;
- challenges;
- космический слой;
- вселенные;
- поздние ветки/режимы как фундамент будущих обновлений.

## 6.2 Сохраняем, но меняем presentation
- crafting;
- trade;
- government;
- religion;
- diplomacy;
- warfare;
- advanced resources;
- space management.

## 6.3 Не показываем в ранней игре
На первых runs скрыты:
- сложная торговая биржа;
- детальный шпионаж;
- большинство government modifiers;
- religion;
- ARPA-подобные поздние мегапроекты;
- challenge genes;
- сложная job optimization;
- большая часть secondary resources.

# 7. Core loops

## 7.1 Micro loop: 10–60 секунд
1. Производство ресурса.
2. Выполнение небольшой цели.
3. Покупка апгрейда/здания.
4. Визуальное изменение.
5. Появление следующей цели.

## 7.2 Session loop: 5–20 минут
1. Получить chapter objective.
2. Стабилизировать производство.
3. Выполнить 1–3 задачи.
4. Открыть новую технологию/систему.
5. Получить визуальный milestone.
6. Начать следующую мини-главу.

## 7.3 Run loop: 1–8 часов
1. Эволюция.
2. Разум.
3. Цивилизация.
4. Промышленность.
5. Кризис / космос.
6. Финал.
7. Хроника.
8. Permanent rewards.
9. Новый timeline.

## 7.4 Meta loop: дни/месяцы
- коллекция видов;
- коллекция концовок;
- генетические ветви;
- планеты;
- реликвии;
- achievements/mastery;
- challenges;
- вселенные;
- поздние mystery arcs;
- Truepath-like content.

# 9. Главный экран

Основная концепция: **Мир-диорама**.

## Desktop
### Левая колонка
- текущая глава;
- следующая веха;
- 3 активные задачи;
- сюжетный индикатор.

### Центр
- живая диорама мира;
- интерактивные зоны;
- визуальные изменения эпох;
- ambient animation.

### Правая колонка
- 5–8 контекстных ресурсов;
- текущие modifiers;
- достижения / награды.

### Нижняя навигация
- Мир;
- Народ;
- Строения;
- Наука;
- Торговля;
- Экспансия.

## Mobile
- верх: 3–4 главных ресурса;
- центр: диорама;
- под ней: Current Objective;
- bottom navigation: Мир / Народ / Строить / Наука / Ещё;
- взаимодействие со зданием открывает bottom sheet.

# 11. Динамическая диорама

Диорама не является полноценным city-builder.

Она собирается из слоёв:
- background;
- terrain;
- settlement stage;
- production overlays;
- animated objects;
- environment state;
- VFX.

Пример состояний:
- Village 1/2/3;
- Town 1/2/3;
- Industrial 1/2/3;
- Atomic;
- Spaceport.

Мелкие эффекты:
- вода;
- дым;
- облака;
- огни;
- жители;
- поезда;
- автомобили;
- дроны;
- ракеты;
- спутники.

## Разные виды
Один и тот же progression template должен визуально менять тему:
- humanoid — города и индустрия;
- plant — органические города;
- fungi — мицелий/подземные сети;
- aquatic — водные поселения;
- avian — вертикальная архитектура;
- synthetic — машинные мегаструктуры;
- demonic — лавовые/ритуальные мотивы.

# 12. Система целей

На экране максимум три уровня.

## 12.1 Current objective
30 секунд – 5 минут.

Пример:
**Постройте первую ферму**  
Награда: +50 пищи, открывает «Хранилище».

## 12.2 Chapter objective
10–30 минут.

Пример:
**Электрифицируйте город**
- построить электростанцию;
- произвести 500 энергии;
- открыть электрический двигатель.

## 12.3 Destiny objective
Крупная цель run.

Пример:
**Переживите Великий фильтр**  
или  
**Покиньте планету**.

---

# 13. Система показа наград

Награда видна **до выполнения**.

Плохой вариант:
> Исследовать электричество.

Нужный вариант:

### Электричество
Открывает:
- ⚡ Электростанцию
- 🏭 Автоматизацию фабрик
- 🌃 Ночное освещение
- 🔬 6 технологий

Кнопка:
**Начать исследование**

# 14. Side quests

Одновременно:
- 3 активных;
- 1 слот story quest;
- 1 слот challenge после нескольких runs.

Категории:
1. исследовательские;
2. экономические;
3. экологические;
4. социальные;
5. технологические;
6. военные/дипломатические;
7. секретные.

Примеры:
- открыть 5 видов;
- прожить 10 минут без голода;
- построить 3 мастерские;
- открыть 10 технологий;
- пройти индустрию без угля;
- объединить мир дипломатией;
- объединить мир силой;
- сохранить коллекцию видов перед Bioseed;
- завершить мегапроект.

## Требование
Side quest должен:
- обучать механике;
- менять стиль игры;
- иметь понятную награду;
- не быть просто «добудь ещё 1000 дерева» без причины.

# 15. Награды и валюты

## Run currencies
Обычные ресурсы конкретной цивилизации.

## Permanent currencies
### Память Архива
Главная prestige currency.

Тратится на:
- ускорение ранних стадий;
- quality-of-life;
- расширение выбора;
- permanent unlocks.

### Генетические образцы
Используются в evolution/meta tree.

### Реликвии
Редкие награды за:
- необычные финалы;
- challenges;
- secret events;
- экспедиции.

## Не валюта
### Хроника
Коллекционный meta-album:
- виды;
- цивилизации;
- планеты;
- концовки;
- события;
- тайны;
- иллюстрации.

---

# 16. Achievements / Mastery

Achievements должны выполнять две роли:
1. permanent bonus;
2. направление игрока к альтернативному контенту.

Категории:
- экономика;
- эволюция;
- технологии;
- разные виды;
- разные финалы;
- необычные ограничения;
- exploration.

Показывать:
- текущий mastery %;
- следующий достижимый bonus;
- 3 рекомендованных достижения.

---

# 17. События и выборы

Каждое крупное событие должно иметь:
- контекст;
- 2–3 выбора;
- preview основных последствий;
- иногда скрытый эффект;
- визуальное изменение;
- запись в Хронике.

Пример:

## Энергетический кризис

### Ископаемое топливо
+ быстрый рост  
+ индустрия  
− загрязнение  
изменяет визуал города

### Чистая энергетика
− медленнее старт  
+ ecology score  
+ специальные поздние технологии

### Атомная программа
+ мощный scientific boost  
+ повышает Filter Risk

# 18. Ветви цивилизации

Основные оси:
- Природа ↔ Индустрия
- Свобода ↔ Контроль
- Кооперация ↔ Доминирование
- Биология ↔ Машины
- Сохранение ↔ Экспансия

Их значения влияют на:
- events;
- визуал;
- available endings;
- некоторые modifiers;
- side quests;
- epilogue.

---

# 19. Финалы / reset states

Reset оформляется как историческая концовка.

Примеры:
- **Пепел** — самоуничтожение;
- **Исход** — покинули планету;
- **Хранители** — симбиоз с биосферой;
- **Сингулярность** — переход к машинной жизни;
- **Империя** — экспансия и подчинение;
- **Вознесение** — выход за пределы материальной формы;
- **За гранью** — межпространственный переход;
- **Разрыв цикла** — поздний meta ending.

После финала:
1. cinematic image;
2. название исхода;
3. статистика цивилизации;
4. ключевые решения;
5. награды;
6. запись в Хронике;
7. новый фрагмент сюжета Архива;
8. CTA «Создать новую жизнь».

---

# 20. Story framework

## Основная рамка
Игрок взаимодействует с древней системой **Архив Жизни**.

Архив способен:
- запускать биосферы;
- наблюдать развитие;
- сохранять память цивилизаций;
- переносить отдельные свойства между timelines.

Главная загадка:
> Почему разумная жизнь снова и снова исчезает?

Постепенно игрок обнаруживает:
1. Архив не просто симулятор;
2. записи повторяют реальные события;
3. timelines оставляют след в настоящей Вселенной;
4. создатели Архива пытались избежать Великого фильтра;
5. некоторые поздние пути связаны с их судьбой.

Подробный сценарный план находится в отдельном документе.

# 21. Первый run

Цель первого run — показать всю продуктовую формулу:
- развитие;
- выбор;
- визуальную эволюцию;
- crisis;
- ending;
- reset;
- permanent reward.

Первый run должен завершиться примерно на 105–120 минуте.

Основной первый финал:
**Пепел**.

Альтернативные финалы начинают полноценно открываться со второго/третьего timeline.

---

# 22. Второй run

Он обязан дать три отличия:
1. старт быстрее;
2. другой вид;
3. появляется новый слой выбора.

Сообщение:
### Архив помнит

Открывается:
- более точное направление эволюции;
- permanent upgrades;

# 23. Offline progression

При возврате:

## Пока вас не было 5 ч 42 мин
Получено:
- пища;
- материалы;
- знания.

Завершено:
- исследования;
- экспедиции.

Обнаружено:
- event/story hook.

### Rewarded option
**Удвоить производственную награду**

Сюжетные открытия и завершённые исследования игрок получает независимо от просмотра рекламы.

# 24. Монетизация

## 24.1 Принципы
- без paywall;
- без рекламы в активной микроигре;
- rewarded даёт ускорение, но не обязательный прогресс;
- fullscreen только в естественных паузах.

## 24.2 Rewarded
Допустимые точки:
- ×2 offline production;
- ускорить экспедицию;
- удвоить side quest chest;
- временный Evolution Boost;
- бесплатный reroll квестов;
- второй artifact roll;
- preview одного скрытого последствия выбора.

## 24.3 Fullscreen
Только:
- после смены эпохи;
- после финала цивилизации;
- при перелёте;
- после большой главы.

### Ограничение
Не показывать fullscreen:
- первые 15 минут;
- чаще заданного cooldown;
- во время управления ресурсами;
- сразу после rewarded.

## 24.4 Banner
Предпочтительно не показывать на главном gameplay screen.

Возможные места:
- Хроника;
- achievements;
- map/encyclopedia;
- menus.

# 27. Ускорение раннего pacing

- убрать стратегию.

# 28. Automation progression

- trade automation;

Это уменьшает повторение знакомых действий и освобождает внимание для новых систем.

# 40. Narrative acceptance criteria

- объяснять reset;
- создавать mystery;
- давать эмоциональный смысл эпохам;
- связывать разные timelines;
- награждать exploration;
- поддерживать разные endings.

# 42. Основные риски

## Scope explosion
Решение: Release 1 заканчивается Bioseed.

## Слишком медленный ранний loop
Решение: отдельный balance pass для первых 120 минут.

## Слишком много UI
Решение: progressive disclosure.

## Новый UI ломает исходную логику
Решение: adapter/state layer + automated smoke tests.

## Арт слишком дорогой
Решение: layered dioramas, а не real city simulation.

## Новые runs ощущаются одинаково
Решение: visuals + traits + events + path choices + automation.

## Сюжет мешает idle
Решение: короткие scenes; Chronicle хранит полные записи.

# Итоговая продуктовая формула

**Хроники Эволюции** — не «улучшенная оболочка Evolve», а визуальная reinterpretation его progression engine:

**Жизнь → Разум → Цивилизация → Кризис → Судьба → Память → Новая жизнь.**

Каждый цикл:
- быстрее;
- визуально богаче;
- стратегически шире;
- открывает новый кусок Вселенной;
- приближает к ответу на вопрос, можно ли пережить Великий фильтр.
