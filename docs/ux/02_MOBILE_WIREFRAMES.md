# Хроники Эволюции — Мобильные вайрфреймы

**Документ:** DS-06  
**Статус:** черновик, в работе  
**Область:** мобильный UX для «Линии времени №1»  
**Основание:** принятые DS-05 и DS-05.5; `PB00–PB30`, `V0–V9`, `C0–C7`

---

# 1. Назначение

Этот документ фиксирует мобильную компоновку для ключевых состояний первого прохождения. Она должна позволять игроку видеть мир, понимать ближайшую цель и действовать одной рукой, не прерывая ощущение непрерывной эволюции.

Вайрфреймы определяют расположение, приоритет и поведение элементов. Они не задают художественный стиль, палитру, финальные тексты или ассеты DS-07–DS-09.

## 1.1. Базовый экран

Опорный размер — `360 × 800` CSS px в портретной ориентации. Макет должен сохранять структуру от 320 px ширины и учитывать верхнюю и нижнюю безопасные зоны устройства.

```text
┌──────────────────────────────────┐
│ безопасная зона                   │
├──────────────────────────────────┤
│ СТАТУСНАЯ ПОЛОСА                  │  48 px
├──────────────────────────────────┤
│                                  │
│                                  │
│           ДИОРАМА МИРА           │  гибкая область,
│                                  │  не меньше 340 px
│                                  │
├──────────────────────────────────┤
│ КАРТОЧКА ТЕКУЩЕЙ ЦЕЛИ             │  72–96 px
│ действие / прогресс / подсказка   │
├──────────────────────────────────┤
│ КОНТЕКСТНАЯ ПАНЕЛЬ                │  64–112 px
│ ресурсы / вкладки / главное       │
│ действие                          │
├──────────────────────────────────┤
│ безопасная зона                   │
└──────────────────────────────────┘
```

- Диорама остаётся доступной в `SCR_WORLD`, `SCR_EVOLUTION`, `SCR_EVENT`, `SCR_MILESTONE` и `SCR_CRISIS`.
- Нижний лист открывается поверх нижней части диорамы; в промежуточном состоянии он занимает до 58% высоты, в полном — до 85%.
- Главное действие располагается в нижней зоне и имеет область касания не меньше 44 px.
- Статусная полоса не становится универсальным счётчиком ресурсов: она показывает только индикаторы, уже открытые и значимые для текущей фазы.

## 1.2. Постоянные элементы

| Элемент | Назначение | Поведение |
|---|---|---|
| Статусная полоса | Эра, время и критический сигнал текущей фазы | Не более трёх индикаторов; не содержит преждевременно открытых систем |
| Диорама | Главный визуальный и смысловой контекст | Нажатие на читаемый объект может открыть контекстную деталь, но не обязательно для прогресса |
| Карточка цели | Показывает, что важно сделать сейчас | Разворачивается для сложной цели; после вехи кратко показывает результат и следующую цель |
| Контекстная панель | Даёт доступ к доступным действиям фазы | Состав меняется вместе с `PB`; старые механики не конкурируют с новыми |
| Нижний лист | Подробности и решения без ухода с мира | Открывается жестом или кнопкой; закрывается жестом, кнопкой закрытия или выбором действия |

# 2. M-00 — зарождение и первая клетка

**Покрытие:** `PB00–PB06`  
**Поверхности:** `SCR_BOOT`, `SCR_WORLD`, `SCR_MILESTONE`, `SCR_EVOLUTION`  
**Состояния:** `V0_PRIMORDIAL` → `V1_CELLULAR`, `C0` → `C2_CELL`

```text
┌──────────────────────────────────┐
│ ПЕРВОБЫТНЫЙ ОКЕАН        00:02    │
├──────────────────────────────────┤
│                                  │
│       живая химическая среда      │
│      [объекты и реакция мира]     │
│                                  │
│                                  │
├──────────────────────────────────┤
│ СОБРАТЬ ПЕРВУЮ ЦЕПЬ               │
│ РНК  3 / 5                        │
├──────────────────────────────────┤
│ РНК 3/5       [ СОЕДИНИТЬ ]       │
└──────────────────────────────────┘
```

### Компоновка и поведение

- `PB00`: минимальный пролог показывает мир, затем без отдельного обучения раскрывает карточку первой цели.
- `PB01`: РНК появляется только в контекстной панели и в требовании цели. Верхняя полоса показывает название эры и время, но не содержит «Энергию» или «Информацию».
- `PB02`: пассивное производство отражается коротким изменением на диораме и числом РНК; отдельный экран для него не открывается.
- `PB03`: при появлении ДНК у контекстной панели возникает вход «Эволюция». Он не вытесняет главное действие и не превращает экран в отдельный режим.
- `PB04`: во время замыкания мембраны карточка цели и нижняя панель приглушаются, но не исчезают надолго; центр внимания остаётся на диораме.
- `PB05`: короткий `SCR_MILESTONE` с заголовком «ЖИЗНЬ» покрывает мир. После него каркас возвращается с контекстом биомассы, а молекулярные действия уходят в подробности.
- `PB06`: «Энергия» впервые появляется в контекстной панели как ресурс метаболизма. До этого бита её нет ни в статусной полосе, ни в скрытом списке.

### Нижний лист «Эволюция»

```text
┌──────────────────────────────────┐
│ ────────  ЭВОЛЮЦИЯ           ×    │
├──────────────────────────────────┤
│ Текущая форма: клетка             │
│ [краткий вид организма]           │
├──────────────────────────────────┤
│ ДОСТУПНЫЙ УЗЕЛ                    │
│ Метаболизм                        │
│ РНК 5/5 · ДНК 1/1                 │
│                    [ ОТКРЫТЬ ]    │
└──────────────────────────────────┘
```

Лист открывается снизу и сохраняет верхнюю часть диорамы видимой. Недоступные будущие системы не показываются как обещания: здесь нет AP, «Познания», работ, зданий или «Напряжения мира».

# 3. M-01 — ветвь клетки и организм

**Покрытие:** `PB07–PB14`  
**Поверхности:** `SCR_WORLD`, `SCR_EVOLUTION`, `SCR_EVENT`, `SCR_MILESTONE`  
**Состояния:** `V1_CELLULAR` → `V2_CREATURE`, `C2_CELL` → `C4_MULTICELLULAR_ORGANISM`

## 3.1. Выбор биологической ветви

`PB07` использует сфокусированный лист «Эволюция», а не универсальное модальное окно. На диораме над клеткой остаются живые предварительные просмотры трёх вариантов.

```text
┌──────────────────────────────────┐
│   ДИОРАМА: клетка + 3 проекции    │
├──────────────────────────────────┤
│ ────────  ВЫБОР ВЕТВИ        ×    │
├──────────────────────────────────┤
│ ПОГЛОЩЕНИЕ                        │
│ захват ресурсов                   │
│                     [ ВЫБРАТЬ ]   │
│ СИМБИОЗ                           │
│ кооперация                        │
│                     [ ВЫБРАТЬ ]   │
│ ОБОЛОЧКА                          │
│ защита                            │
│                     [ ВЫБРАТЬ ]   │
└──────────────────────────────────┘
```

- Нажатие на вариант временно акцентирует соответствующую проекцию в диораме и раскрывает короткое следствие.
- Подтверждение выбора закрепляет визуальную идентичность ветви для `PB08–PB14`.
- Варианты не требуют дополнительного экрана подтверждения: выбор необратим, но его последствия прямо показаны на живом мире и в листе.

## 3.2. AP, многоклеточность и «Познание»

```text
┌──────────────────────────────────┐
│ ЭРА ОРГАНИЗМА          AP 2        │
├──────────────────────────────────┤
│                                  │
│      организм в своём биоме       │
│                                  │
├──────────────────────────────────┤
│ УСИЛЬТЕ ТЕЛО                      │
│ Выберите адаптацию                │
├──────────────────────────────────┤
│ [ ЭВОЛЮЦИЯ ]  [ ПОВЕДЕНИЕ ]       │
└──────────────────────────────────┘
```

- `PB09`: AP впервые появляется в статусной полосе рядом с входом в «Эволюцию». До этого момента область не резервируется и не выглядит как пустой счётчик.
- Карточка адаптации в полном листе содержит стоимость AP, одно предложение об эффекте и предварительный просмотр изменяемой части тела. Она не выдаёт новую несвязанную форму организма.
- `PB10`: веха «МНОГОКЛЕТОЧНОСТЬ» кратко занимает экран; камера расширяется от колонии к единому телу, затем возвращается к обычной компоновке.
- `PB11`: главный вызов карточки цели ведёт в лист «Эволюция», а не открывает россыпь отдельных действий внизу экрана.
- `PB12`: «Познание» добавляется третьим индикатором статусной полосы только после нервной системы. При нехватке места время уступает место и доступно в подробностях.
- `PB13`: поведенческий выбор открывается компактным листом над диорамой; варианты должны быть связаны с читаемыми объектами и ситуацией мира.
- `PB14`: веха разумной жизни скрывает биологическую нижнюю панель. После перехода прежние адаптации доступны как история в «Эволюции», но не как основной набор действий.

# 4. M-02 — племя, город, индустрия и современность

**Покрытие:** `PB15–PB24`  
**Поверхности:** `SCR_WORLD`, `SCR_EVENT`, `SCR_MILESTONE`, `SCR_CHRONICLE`  
**Состояния:** `V3_SAPIENT` → `V7_MODERN`, `C5_SAPIENT_GROUP` → `C7_CIVILIZATION`

```text
┌──────────────────────────────────┐
│ ГОРОД                НАС. 42       │
├──────────────────────────────────┤
│                                  │
│      поселение / город / регион   │
│     [нажимаемые объекты мира]     │
│                                  │
├──────────────────────────────────┤
│ ПОСТРОЙТЕ ПЕРВУЮ МАСТЕРСКУЮ        │
│ Дерево 4/6 · Труд 2/3             │
├──────────────────────────────────┤
│ [ РАБОТЫ ] [ ЗДАНИЯ ] [ ХРОНИКА ] │
└──────────────────────────────────┘
```

## 4.1. Ранний разум и племя

- `PB15`: первый небольшой коллектив показывает население только как число групп и ролей. В диораме не появляются мелкие индивидуальные счётчики.
- `PB16`: «Племя» получает короткую веху, после которой выбор совместного использования ресурсов открывается в листе события. Решение записывается в «Хронику» и профиль мира.
- `PB17`: нижняя панель становится набором трёх устойчивых входов: «Работы», «Здания», «Хроника». Карточка цели остаётся выше неё и не смешивается с каталогом.
- `PB18`: «Следы до нас» показываются как объект в месте строительства или раскопок. Выбор привязан к точке диорамы и не требует отдельной карты.

## 4.2. Работы и здания

```text
┌──────────────────────────────────┐
│ ────────  РАБОТЫ              ×   │
├──────────────────────────────────┤
│ ДОБЫЧА                  2 группы  │
│ [ − ]                       [ + ] │
│ СТРОИТЕЛЬСТВО            1 группа │
│ [ − ]                       [ + ] │
│ ИССЛЕДОВАНИЯ             0 групп  │
│ [ − ]                       [ + ] │
├──────────────────────────────────┤
│ свободно: 1          [ ПРИМЕНИТЬ ]│
└──────────────────────────────────┘
```

- Лист работ использует короткие строки с шагом изменения, числом назначенных групп и видимым остатком. Он не превращается в таблицу всех исторических ресурсов.
- Лист зданий показывает только доступные текущей фазе постройки, стоимость и эффект на текущую цель; действие строит или ставит в очередь в том же листе.
- `PB19`: «Хроника» становится постоянным третьим входом. Её лист даёт последовательную историю ключевых решений и накопленного знания, а не журнал каждого производственного тика.
- `PB20`: механизация добавляет новые роли и здания, но не добавляет «Энергию» до `PB21`.

## 4.3. Энергия, современность и ERROR 17

```text
┌──────────────────────────────────┐
│ МАШИННЫЙ ВЕК       ЭНЕРГИЯ 12      │
├──────────────────────────────────┤
│                                  │
│   производственный регион мира    │
│                                  │
├──────────────────────────────────┤
│ СТАБИЛИЗИРУЙТЕ СЕТЬ               │
│ Энергия 12/16                     │
├──────────────────────────────────┤
│ [ РАБОТЫ ] [ ЭНЕРГИЯ ] [ ХРОНИКА ]│
└──────────────────────────────────┘
```

- `PB21`: веха «Машинный век» завершается появлением «Энергии» в статусной полосе и отдельного входа в нижней панели. Это первое активное представление ресурса.
- `PB22`: энергетический кризис использует лист события с тремя вариантами. Нажатие на вариант показывает на диораме постоянное последствие: тяжёлую индустрию, чистую генерацию или исследовательский атомный профиль.
- `PB23`: в современности диорама расширяется до связанного регионального или мирового вида; нижняя панель сохраняет ту же структуру, чтобы масштаб мира не ломал навигацию.
- `PB24`: строка статуса или карточка цели кратко показывает «Прогноз завершения цикла: доступен» → `ERROR 17` → запрет доступа. Аномалия не меняет экран, не скрывает современный мир и не использует хоррор-эффекты.

# 5. M-03 — Атомный век и кризис

**Покрытие:** `PB25–PB27`  
**Поверхности:** `SCR_MILESTONE`, `SCR_CRISIS`, `SCR_EVENT`  
**Состояние:** `V8_ATOMIC`, `C7_CIVILIZATION`

```text
┌──────────────────────────────────┐
│ АТОМНЫЙ ВЕК     НАПРЯЖЕНИЕ  68%    │
├──────────────────────────────────┤
│                                  │
│     мир с реактором и сбоями      │
│                                  │
├──────────────────────────────────┤
│ КРИТИЧЕСКАЯ ФАЗА                  │
│ Предупреждение требует решения    │
├──────────────────────────────────┤
│ [ СОБЫТИЕ ]      [ ПРОТОКОЛ ]     │
└──────────────────────────────────┘
```

- `PB25`: веха «МЫ РАСКОЛОЛИ МАТЕРИЮ» показывает мир с конкретной программой реактора или лаборатории. После закрытия вехи появляется «Напряжение мира»; до этого места в статусной полосе для него нет.
- В `PB26` статусная полоса показывает эру и «Напряжение мира». Обычные ресурсы, работы и здания сворачиваются в один вход «Мир» и не конкурируют с кризисными решениями.
- Карточка цели меняет роль на карточку критической фазы: название угрозы, одно текущее требование и ближайшее действие. Она не скрывает числовое напряжение.
- События кризиса открываются в листе до 58% высоты и оставляют диораму видимой. Последствия отражаются ступенчато: предупреждение, нарушения, критическая фаза.

## 5.1. «Последний протокол»

```text
┌──────────────────────────────────┐
│       ДИОРАМА АТОМНОГО МИРА       │
│                                  │
├──────────────────────────────────┤
│ ────────  ПОСЛЕДНИЙ ПРОТОКОЛ      │
│                                  │
│ Решение будет зафиксировано.      │
│                                  │
│ [ отменить ]   [ ПОДТВЕРДИТЬ ]    │
└──────────────────────────────────┘
```

`PB27` использует сфокусированный лист высотой до 70%. После подтверждения все игровые элементы управления блокируются, лист закрывается, мир остаётся на короткую паузу и только затем переходит к белой вспышке. Отмена возвращает игрока в `SCR_CRISIS` без потери контекста.

# 6. M-04 — «Пепел», «Архив» и новый запуск

**Покрытие:** `PB28–PB30`  
**Поверхности:** `SCR_ENDING`, `SCR_ARCHIVE`, `SCR_META`  
**Состояние:** `V9_ASH`

## 6.1. Финал «Пепел»

```text
┌──────────────────────────────────┐
│                                  │
│     тёмная неподвижная диорама    │
│           собственного мира       │
│                                  │
│      ЦИВИЛИЗАЦИЯ №1 ЗАВЕРШЕНА     │
│              ПЕПЕЛ               │
│                                  │
│       [ СОХРАНИТЬ В АРХИВ ]       │
└──────────────────────────────────┘
```

- `PB28` сначала оставляет почти пустой экран и пепельную версию мира игрока. Заголовок и действие появляются после визуальной паузы.
- На этом экране нет статусной полосы, цели, ресурсов и навигации: это результат, а не обычный игровой режим.

## 6.2. Сводка «Архива»

```text
┌──────────────────────────────────┐
│ ←  АРХИВ                          │
├──────────────────────────────────┤
│ ЛИНИЯ ВРЕМЕНИ №1                  │
│ пепельная миниатюра мира          │
├──────────────────────────────────┤
│ ВИД И АДАПТАЦИИ               ›   │
│ ПУТЬ ЦИВИЛИЗАЦИИ              ›   │
│ КЛЮЧЕВЫЕ РЕШЕНИЯ              ›   │
│ КРИЗИС И ФИНАЛ                ›   │
│ ФРАГМЕНТЫ АРХИВА              ›   │
├──────────────────────────────────┤
│       [ ПРОДОЛЖИТЬ ]              │
└──────────────────────────────────┘
```

- `PB29`: «Архив» — полноэкранная, прокручиваемая запись одной истории. Секции сворачиваются по умолчанию, кроме краткого вида мира и названия линии времени.
- Внутри отражаются вид, адаптации, путь цивилизации, ключевые решения, пик населения, кризис, подтип финала и фрагменты «Архива».
- Порядок раскрытия ведёт от живого мира к сделанным решениям и финалу, а не от набора чисел к оценке игрока.

## 6.3. Память «Архива»

```text
┌──────────────────────────────────┐
│                                  │
│     спокойная нейтральная среда   │
│      [запись Линии времени №1]    │
│                                  │
│          АРХИВ ПОМНИТ             │
│   Мы можем изменить результат.    │
│                                  │
│  [ СОЗДАТЬ НОВУЮ ЖИЗНЬ ]          │
└──────────────────────────────────┘
```

`PB30` оставляет предыдущую линию времени видимой как запись и ведёт к ускоренному знакомому началу «Линии времени №2». Это не сброс данных и не экран поражения.

# 7. Сводка покрытия

| Мобильный вайрфрейм | Биты | Главная задача |
|---|---|---|
| M-00 | `PB00–PB06` | Ввести мир, ресурсы и первую клетку без перегруженной верхней панели |
| M-01 | `PB07–PB14` | Показать выбор ветви, AP, организм и переход к разумной жизни |
| M-02 | `PB15–PB24` | Перевести интерфейс к работам, зданиям, «Энергии» и современному миру |
| M-03 | `PB25–PB27` | Сжать обычный интерфейс вокруг «Напряжения мира» и «Последнего протокола» |
| M-04 | `PB28–PB30` | Завершить историю через «Пепел», «Архив» и новый запуск |

Каждый бит `PB00–PB30` остаётся в порядке и смысловом значении принятого контракта. Следующий этап DS-06 адаптирует эту же иерархию для настольного экрана, не добавляя отдельной логики игры.
