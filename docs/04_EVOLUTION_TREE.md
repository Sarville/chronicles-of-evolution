# Хроники Эволюции — дерево эволюции

**Версия:** evolution tree v1.0  
**Область:** Timeline #1 + каркас ветвления для следующих timelines.  
**Связь с экономикой:** биологические узлы оплачиваются Information + Energy/Biomass; цивилизационные — Knowledge + Materials/Food/Power; мета-узлы Архива — Archive Fragments.

---

# 1. Принцип дерева

Дерево должно давать ощущение настоящего ветвления, но не превращать первый двухчасовой цикл в ловушку, где «неправильный» выбор делает прохождение невозможным.

Поэтому узлы делятся на четыре типа:

- **CORE** — обязательный ствол. Открывает новую ступень сложности.
- **BRANCH** — выбор специализации. Обычно одновременно активна одна ветвь уровня.
- **OPTIONAL** — полезная адаптация, которую можно пропустить.
- **CONVERGENCE** — точка, в которой разные ветви снова позволяют двигаться дальше.

В Timeline #1 branch choice влияет прежде всего на стиль экономики и визуальную форму. После первого reset Архив начинает позволять сохранять отдельные свойства между timelines и собирать гибриды.

# 2. Валюты дерева

## Биологическая часть, 0–46 мин

- **Information (I)** — основной ресурс эволюционных узлов;
- **Energy (E)** — цена за активные/энергозатратные признаки;
- **Biomass (B)** — цена за усложнение тела.

## Цивилизационная часть, 46–120 мин

- **Knowledge (K)** — основной ресурс технологий;
- **Materials (M)** — инфраструктурная цена;
- **Food (F)** — цена расширения общества;
- **Power (PWR)** — цена поздней индустрии.

## После reset

- **Archive Fragments (AF)** — постоянные мета-разблокировки.

# 15. Как branch choices меняют экономику

Чтобы выбор чувствовался, но не ломал 120-минутный pacing:

- обычный branch даёт преимущество **10–30%** в одном направлении;
- штраф альтернативной ветви не больше **10–15%**;
- обязательные breakthrough costs одинаковы для всех ветвей;
- каждая branch-комбинация должна укладываться в first reset **110–130 минут**;
- ни одна ветвь не должна быть строго доминирующей по итоговому времени.

### Целевые стили

| Ветка | Быстрее | Слабее | Для какого игрока |
|---|---|---|---|
| Photosynthesis | пассивный Energy | burst growth | idle / спокойный |

# 16. UI дерева

На мобильном нельзя показывать всё дерево сразу.

## Основной режим

- вертикальный ствол текущей эры;
- branch nodes раскрываются вбок максимум на 2–3 карточки;
- будущие эры видны как силуэты/названия без деталей;
- завершённые эры схлопываются в один компактный блок;
- tap на блок открывает историю выбора.

## Цветовой смысл

Цвет не должен быть единственным носителем информации:

- CORE — круглая/центральная форма;
- BRANCH — ромб;
- OPTIONAL — малый шестиугольник;
- CONVERGENCE — крупный двойной контур;
- ARCHIVE — отдельная «звёздная» форма.

## Состояния узла

- locked;
- visible but unmet prerequisites;
- affordable;
- selected;
- completed;
- abandoned branch;
- preserved by Archive.

# 18. Что переносится между timelines

По умолчанию после reset **не переносится**:

- ресурсы;
- population;
- buildings;
- обычные upgrades;
- выбранные branches текущей timeline.

Переносится:

- Archive Fragments;
- открытые Archive nodes;
- discovered evolution nodes;
- codex/lore;
- записи о кризисных решениях;
- achievements;
- визуальная история прошлых timelines.

После покупки `Сохранённая адаптация` игрок может переносить один OPTIONAL biological node, а более поздние Archive upgrades разрешают перенос branch traits.

# 19. Главный принцип следующих timelines

Timeline #2 не должна быть просто «та же игра ×2 быстрее». Она должна задавать вопрос:

> Что изменится, если жизнь снова пройдёт тот же путь, но с памятью о предыдущем провале?

Поэтому дерево рассчитано так, чтобы в будущих циклах можно было:

- совмещать ранее взаимоисключающие признаки;
- открывать новые convergence nodes;
- раньше видеть признаки Великого фильтра;
- менять социальную и энергетическую модель цивилизации;
- в перспективе пережить «Пепел» и перейти к космической фазе.

Первый reset — не конец дерева, а момент, когда игрок впервые понимает, что **само дерево является игровым объектом**.
