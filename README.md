# Хроники Эволюции

**Хроники Эволюции** — сюжетная incremental-стратегия о развитии жизни и цивилизаций: от первой самореплицирующейся молекулы до города, индустрии, космоса и множества вариантов будущего.

Каждый запуск — отдельная история мира. Завершение цивилизации не обнуляет прогресс: её открытия и память становятся частью Архива и влияют на следующие временные линии.

## О проекте

Игра строится вокруг понятных ближайших целей, визуального отражения роста мира и постепенного открытия сложных систем. В первом сценарии игрок создаёт жизнь, проводит её через эволюционные развилки, развивает разумный вид до цивилизации и сталкивается с первым кризисом. Последующие прохождения раскрывают новые виды, пути развития, планеты и финалы.

Подробная концепция и план первого вертикального среза находятся в [docs](docs/):

## Запуск и сборка

Требуется Node.js. Установите зависимости и запустите локальный сервер:

```bash
npm install
npm run serve
```

Основные команды:

```bash
npm run build        # собрать игру и энциклопедию
npm run build-debug  # отладочная сборка
```
